# Kharcha visual direction — finance-first light UI

This redesign uses contemporary personal-finance interfaces as visual inspiration only. Kharcha keeps its own product scope, Nepal-first workflows, content, brand, data model and interaction logic.

## Principles

1. **Money first**
   - The primary balance/net amount has the strongest hierarchy.
   - Income, spending and budget information remain secondary but immediately scannable.

2. **Light financial canvas**
   - Soft neutral app background.
   - White functional surfaces.
   - Thin separators and subtle elevation instead of heavy dark cards.

3. **Kharcha emerald**
   - Existing Kharcha mint direction is retained as a deeper accessible emerald for actions, progress and selected states.
   - Blue is reserved for positive/income semantics; red is reserved for expense/error semantics.

4. **Compact hierarchy**
   - Tighter card padding and radii.
   - Larger financial values, smaller metadata.
   - Section headings and actions use consistent alignment.

5. **One interaction language**
   - Filled emerald = primary action.
   - White/outlined = secondary action.
   - Soft emerald pills = selected filter state.
   - Minimum 44 px touch targets.

6. **Categories remain recognisable**
   - Existing category emoji are kept because they are already part of Kharcha's category language.
   - Core app chrome avoids decorative emoji and uses restrained text/glyph navigation.

7. **No product borrowing**
   - No AI assistant, banking, transfers, onboarding, authentication, or reference-app copy is introduced by this redesign.
   - No financial calculations, storage behavior, Nepal-specific flows, or feature scope are changed.

## Screen direction

- **Overview:** open balance hierarchy, compact wallets, single budget card, continuous recent-activity list.
- **Activity:** search/filter controls read as lightweight tools rather than cards.
- **Budget:** forms and category budgets use the same white-surface system.
- **Insights:** planning, Nepal tools, savings and household modules inherit one consistent card treatment.
- **Sheets/modals:** white bottom sheets, light inputs, emerald primary buttons.
- **Navigation:** white bottom bar, emerald active state, circular central add action.
